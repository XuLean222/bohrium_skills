# 分类流程与输出列说明

## 流水线顺序

1. 读取 Excel（必须包含 **query** 列）
2. **能力分类** → 能力类别、置信度、判断理由
3. **学科+领域分类** → 学科、领域（规则优先，LLM 兜底）
4. **意图分类** → 主意图、隐含意图、动作、限制条件（多列展开）
5. 合并所有列写出 Excel

## 输出列一览

| 分类 | 输出列 |
|------|--------|
| 能力 | 能力类别、能力类别置信度、能力类别判断理由 |
| 学科/领域 | 学科、领域 |
| 意图 | 主意图名称、主意图置信度、主意图判断理由 |
| 意图 | 隐含意图1名称、隐含意图1置信度、隐含意图1判断理由（及 2、3… 按需） |
| 意图 | 动作1名称、动作1置信度、动作1判断理由（及 2、3… 按需） |
| 意图 | 限制条件1名称、限制条件1置信度、限制条件1判断理由（及 2、3… 按需） |
| 其他 | query字数 |

## 安全说明

- API 密钥、Endpoint 等均通过**环境变量**读取，本包内不包含任何密钥或隐私信息。
- 分发给他人时只需提供本文件夹；对方自行配置自己的 Azure OpenAI 即可使用。
